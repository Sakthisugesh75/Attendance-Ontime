# Attendance Desk

## Design system

Read @DESIGN.md before writing any UI (v4 "Glass": §0 overrides older values; visual reference `docs/design/design-v4.html`; 3D art rules and `docs/design/design-v5-3d.html` in §0). Use only the tokens and component patterns defined there. Never introduce new colors, fonts or shadows.

- Tokens: `app/styles/design-tokens.css` (CSS variables + Tailwind v4 names such as `bg-surface`, `text-ink-3`, `bg-st-late-tint`).
- Visual reference for every token and component: `docs/design/design-preview.html` (open it in a browser).
- Research behind the system: `docs/design/design-refs/ANALYSIS.md`.
